# 🌊 AQUA SPHERE — Премиальный Дайвинг Клуб

> Фотореалистичный, кинематографичный веб-сайт дайвинг-клуба **AQUA SPHERE**, вдохновленный оригинальным концептом и выполненный в эстетике глубоководного погружения.

---

## 🌟 Основные особенности

- **Кинематографичный Hero-экран**:
  - Парящий силуэт дайвера в невесомости с поднимающимися пузырьками воздуха из легочного автомата.
  - Пробивающиеся сверху сквозь толщу воды объемные солнечные лучи (God Rays).
  - Биолюминесцентные кораллы по левому и правому краю.
  - Изысканная типографика на русском языке (*Cormorant Garamond* & *Cinzel*).
- **3D Underwater Scene (Three.js & WebGL)**:
  - 450+ парящих частиц морского планктона с органическим дрейфом.
  - Струящиеся всплывающие пузырьки воздуха с физическим покачиванием.
  - Мерцающие световые каустики на глубине океана.
  - Интерактивный параллакс камеры, синхронизированный с движением мыши и скроллом.
- **О Клубе ("О КЛУБЕ")**:
  - Фотореалистичная крылатая рыба-бабочка (морской петух) с трепещущими плавниками и реакцией на курсор.
  - Историческая справка («С 2012 ГОДА») и тонкий розовый разделитель с неоновым свечением.
  - Достижения клуба в виде метрик.
- **Локации ("ЛОКАЦИИ")**:
  - Интерактивный путеводитель по ключевым мировым спотам (Красное море, рэки Черного моря, озера Подмосковья, Индонезия/Мальдивы).
  - Пара тропических рыб, плывущих в толще воды.
  - Стая тропических рыбок, проплывающих по нижней дорожке.
  - Панорамный коралловый риф в основании экрана.
- **Курсы Дайвинга ("КУРСЫ")**:
  - Карточки: *Beginner Diving*, *Advanced Diving*, *Deep Sea Exploration*.
  - Глубина, продолжительность, международная сертификация PADI/CMAS.
  - Микро-взаимодействия с 3D-приподниманием карточек при наведении.
- **Номера и Оборудование ("НОМЕРА")**:
  - Маски с панорамным обзором, гидрокостюмы 3–7мм, баллоны Nitrox и тренировочный бассейн 5м.
- **Интерактивная Фотогалерея с Лайтбоксом**:
  - Асимметричная сетка с возможностью полноэкранного просмотра фотографий высокого разрешения.
  - Управление клавишей `ESC` и кликом по оверлею.
- **Форма Бронирования ("ЗАПИСАТЬСЯ")**:
  - Выбор курса, даты, уровня опыта и контактов.
  - Клиентская валидация данных.
  - Праздничный салют конфетти при успешной отправке заявки.
- **Атмосферный звук океана**:
  - Процедурный генератор подводного низкочастотного эмбиента на Web Audio API (работает без необходимости внешних файлов).

## 🛠 Технологический стек

- **React 19** + **Vite 8**
- **Three.js** (WebGL 3D частицы, свет, каустики, параллакс)
- **GSAP & ScrollTrigger** (кинематографичные скролл-анимации и реверсивная перемотка)
- **Lucide React** (набор векторных иконок)
- **Canvas-Confetti** (эффект успешной отправки заявки)
- **CSS3 Variables & Animations** (аппаратное ускорение через GPU)

## 🚀 Запуск и сборка

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки (Dev Server)
```bash
npm run dev
```
После запуска откройте `http://localhost:5173` в браузере.

### 3. Сборка для Production
```bash
npm run build
```
Готовая оптимизированная сборка будет сгенерирована в директорию `dist/`.

### 4. Предпросмотр сборки
```bash
npm run preview
```
